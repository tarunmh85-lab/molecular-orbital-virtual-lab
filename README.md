# ⚛️ Molecular Orbital Theory Virtual Lab
## 🌐 Live Demo

Try the application here:

https://molecular-orbital-virtual-lab-2jwzlkmzzrgxiwuuhame84.streamlit.app/

An interactive educational web application designed to help students understand Molecular Orbital Theory through molecular analysis, electron configurations, bond order calculations, and magnetic properties.

## 🚀 Features

- **Concept Learning:** Understand bonding orbitals, antibonding orbitals, bond order, and magnetic properties.
- **Molecular Analysis:** Explore 10 selected diatomic molecules: H₂, He₂, Li₂, Be₂, B₂, C₂, N₂, O₂, F₂, and Ne₂.
- **Electron Configuration:** View molecular orbital electron arrangements.
- **Bond Order Calculation:** Calculate bond order using the Molecular Orbital Theory formula.
- **Magnetic Properties:** Identify paramagnetic and diamagnetic molecules.
- **Interactive Quiz:** Test your knowledge with 10 multiple-choice questions.
- **PDF Report:** Generate and download an experiment report.

## 💻 Run Locally

1. Clone this repository:

   `git clone YOUR_GITHUB_REPOSITORY_URL`

2. Open the project folder.

3. Install the required libraries:

   `python -m pip install -r requirements.txt`

4. Run the application:

   `python -m streamlit run app.py`

## 📚 Educational Scope

This project uses a curated, simplified Molecular Orbital Theory model for selected diatomic molecules. It is intended for educational purposes and is not a general-purpose quantum chemistry calculator.
